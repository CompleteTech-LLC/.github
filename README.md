# CompleteTech-LLC community health files

This repository holds the organization landing page and the default community health files for public repositories under [CompleteTech-LLC](https://github.com/CompleteTech-LLC), published by Complete Tech LLC.

| File | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | The organization landing page shown at github.com/CompleteTech-LLC. |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to propose changes. |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability. |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Expected behavior. |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask questions. |

GitHub applies these as defaults to any repository in the organization that does not have its own copy.
