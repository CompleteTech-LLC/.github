# Contributing

Thanks for your interest in Complete Tech LLC projects. These defaults apply to public repositories in the organization unless a repository has its own `CONTRIBUTING.md`.

## Before you start

- Read the repository README to see what the project does and its current status.
- For anything larger than a small fix, open an issue first so we can agree on direction.
- Check for an existing issue or pull request on the same topic.

## Making a change

1. Fork the repository and create a branch from the default branch.
2. Keep the change focused: one concern per pull request.
3. Run the tests or checks the repository documents, and add or update tests when behavior changes.
4. Update documentation if the change affects usage.
5. Open a pull request describing what changed and why, and how you verified it.

## Ground rules

- Do not commit secrets, credentials, or personal data.
- State limits honestly: do not claim features or results the code does not demonstrate.
- By submitting a contribution you agree it may be distributed under the repository's license. Licenses vary by repository.
- Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).

Security issues should not be filed as public issues; see [SECURITY.md](SECURITY.md).
